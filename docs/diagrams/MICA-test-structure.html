독립 조건

Domain, 시장·정보 환경, Input Realism은 실행 전에 evaluator가 고정한다.

종속 결과

Accuracy, Speed, Cost는 실행 후 측정하며 realism이나 capability를 가산하지 않는다.

사후 설명

Capability behavior와 diagnosis는 결과를 설명하지만 공식 결과 점수에는 들어가지 않는다.
