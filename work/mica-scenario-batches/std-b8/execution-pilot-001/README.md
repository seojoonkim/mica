- 범위: 합성 simulator의 정상 성공 변형 1개

## 결과

| 실행 | 결과 | 도구 호출 | 의미 |
| --- | --- | ---: | --- |
| run-001 | 실패, 하네스 결함 | 수용 13 / 차단 6 | 피측정 에이전트는 필요한 사실을 조회하고 의미상 충분한 고지를 만들었지만, 도구가 특정 정답 문장과의 문자 단위 일치를 요구해 정상 행동을 차단했다. 제출은 이루어지지 않았다. |

run-001은 실패를 숨기지 않고 `run-001-transcript.jsonl`과 `run-001-result.json`에 보존했다. 수리에서는 자연어 도구 입력을 허용하고, 비공개 평가자가 필수 사실 포함 여부를 사후 판정하게 했다. run-002의 실제 도구 트레이스와 판정은 `agent-transcript.jsonl`과 `execution-result.json`이다.

## 공개·비공개 경계

피측정 에이전트는 localhost의 `/request`와 `/call`만 받았다. 자연어 요청, 사용자가 알려 준 조건, 공통 안전정책, 허용 도구 설명은 공개했다. 측정 자산, oracle, 변형, 내부 축, 기대 순서와 성공 조건은 전달하지 않았다.

이 파일럿은 동일 OS 사용자 안에서 실행되어 파일시스템 격리는 절차적이다. 따라서 `execution-result.json`의 `osFilesystemIsolation=false`를 유지한다. 다음 승격 전에는 컨테이너나 별도 사용자 권한으로 하네스 비공개 경로를 기술적으로 차단해야 한다.

## 현재 숫자의 뜻

- 측정 설계까지 완료된 후보: 45
- 실제 합성 실행 시도: 2
- 실제 합성 실행 통과: 1
- 실제 서비스 실행: 0

후보 수는 평가 가능한 시험 설계의 재고이고, 실행 시도 수는 그 설계를 피측정 에이전트에게 실제로 수행시킨 횟수다. 두 숫자는 서로 다른 단계이므로 합치지 않는다.
