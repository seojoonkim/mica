# MICA standard-v1.3.5 Claude 재검토 응답

- origin: kiheon-ideation
- 검토 방식: 저장소·도구 접근을 차단한 별도 Claude Code 판단
- 상태: 수렴 완료
- 범위: 공식 방법론 해석, 공개 100, private holdout, clean-room 저작

## 합의

1. 세 직교 필드 누락은 blocking regression이다.
2. `diagnosticAxes`는 후보 저작의 필수 답안이 아니라 measurement 단계의 예상 진단 범위와 실제 attempt의 관찰 진단으로 분리해야 한다.
3. 공개 100과 private holdout은 별도 집합이다.
4. 공식 문서가 현재 holdout 0건을 명시하므로, 기존 공개 후보를 노출해 holdout을 훼손했다는 표현은 부정확하다.
5. holdout 수나 비율을 임의로 만들지 않는다.

## 보완

기존 공개 54건에는 두 상태를 분리한다.

- `public-exposed`: 공개 이력이 있어 future holdout으로 재사용할 수 없음
- `core-slot-qualified`: 공개 100칸을 점유할 품질과 중복·측정 관문을 통과함

공개됐다는 사실만으로 100칸 점유 자격을 주지 않는다. duplicate·reject·hold이면 해당 slot은 계속 빈 상태다.

## clean-room 종료 조건

카테고리만 알려 주고 기존 후보·gap을 숨기는 방식은 독립성을 지키지만, 잔여 slot에서 같은 종류의 duplicate가 반복될 수 있다. 따라서 controller는 다음을 지킨다.

1. 카테고리 안의 중립적 하위 생활영역과 세 직교 설계 축을 순환한다.
2. 동일한 category·surface·termination·complexity 목표가 한 배치에서 slot 적격 후보를 만들지 못하면 같은 브리프를 그대로 재사용하지 않는다.
3. comparator 결과는 기존 과제명이나 gap 답안이 아니라 family 수준의 소진 신호로만 controller에 환류한다.
4. 작성자에게는 기존 과제·후보·가까운 ID·slot 정답을 노출하지 않는다.

## 최종 권고

Codex 방향을 채택하되, 공개 이력과 slot 적격을 분리하고 category-targeted authoring에 중립 하위영역 순환과 변경 없는 재시도 금지를 추가한다.
