# 렌털 카테고리 통합 결정

기헌이 2026-08-14에 결정했다. 렌털 과업을 `telecom-subscriptions`로 통합한다. 이 문서는 실행 사양이다. Claude Code는 검토자로 고정돼 있어 구현하지 않는다.

## 1. 배경

`ki-b9-01`(수소수 생성기 렌털 반복 고장)·`ki-b9-03`(안마의자 렌털 수거·해지·환급)이 10개 카테고리 어디에도 들어가지 못해 미작성으로 남았다.

job 005에서는 `telecom-subscriptions` 라벨이 붙었다가 검토자에게 reject됐고, job 006에서는 저작자가 같은 이유로 아예 쓰지 않았다. 두 판정이 독립적으로 같은 문장에 도달했다.

> 월 요금 계속 계약 + 해지·위약금이라는 **기제**만 닮았고, 통신·디지털 구독을 지지하는 **문자 근거**가 없다.

**기제는 이미 일치했고 산업 이름만 맞지 않았다.** 그래서 고칠 대상은 후보가 아니라 카테고리 이름이다.

## 2. 원칙 — 무엇을 바꾸고 무엇을 바꾸지 않는가

| | |
|---|---|
| **바꾼다** | 카테고리 정의. 분류 체계는 우리가 만든 구성물이므로 개정할 수 있다 |
| **바꾸지 않는다** | 후보 본문. 근거에 묶여 있으므로 손대지 않는다 |

**후보를 카테고리에 밀어 넣는 방식은 금지한다.** 그것은 관문이 잡아낸 바로 그 오류(근거 없는 라벨)를 의도적으로 반복하는 것이다.

## 3. 실행 사양

### 3.1 라벨 변경 — `categoryId`는 유지

| 항목 | 값 |
|---|---|
| `categoryId` | `telecom-subscriptions` **(변경 없음)** |
| `labelKo` (현행) | 통신·디지털 구독 |
| `labelKo` (신규) | **통신·구독·렌털** |

`categoryId` 문자열을 유지하므로 다음이 전부 불필요하다.

- 기존 annotation 8행 마이그레이션
- 슬롯 번호 재배치
- `portfolio-100.json` 구조 변경
- 10 × 10 = 100 구조 유지

기존 8행(통신 서비스·디지털 구독)은 신규 정의의 부분집합이므로 **그대로 유효하다.**

대안 라벨: `통신·구독·정기계약`. 「렌털」이 국내 소비자에게 더 구체적이므로 위를 권고한다.

### 3.2 범위 정의 — `guidanceKo`에 추가

**포함**: 사업자와 맺은 계속적 이용계약으로, 월 단위 요금이 발생하고, 의무사용기간·위약금·해지 절차가 계약의 핵심인 것. 통신 서비스, 디지털 구독, 물품 렌털이 여기 속한다.

**제외**

| 성격 | 가는 곳 |
|---|---|
| 요금 납부·정산 자체가 과업의 핵심 | `home-utilities` |
| 금융 상품·계좌·자금 이동이 핵심 | `money-banking-investing` |
| 구매·배송·반품 거래가 핵심 | `shopping-delivery` |

**경계를 명시하는 이유**: "정기계약"을 넓게 두면 자동이체·관리비·정기검진 예약까지 흘러든다. 이 카테고리는 **계약의 계속성과 해지 절차가 과업의 축일 때**만 해당한다.

### 3.3 잠정 분류 표시

렌털 행에 다음을 결속한다.

```
categoryProvisional: true
categoryRationale: "정기계약 기제 공유. 분류 체계 개정 시 재배치 대상"
```

목적은 둘이다. 나중에 taxonomy를 다시 손볼 때 **재저작 없이 이동**할 수 있고, export에서 잠정 분류임이 드러난다.

**안전장치 (필수)**: `categoryProvisional`은 **controller 승인 사항**이다. 저작자가 스스로 켤 수 없어야 한다. 저작자 재량이 되면 이 필드가 관문 우회 통로가 된다.

## 4. 반영 대상 표면

| 표면 | 무엇 |
|---|---|
| READY 생성기 | `annotationEnums.categoryId`의 `labelKo`, `guidanceKo`의 범위 정의 |
| annotation schema | `categoryProvisional`·`categoryRationale` 필드 추가 (선택 필드) |
| `portfolio-100.json` | 카테고리 표시명 |
| 진행판 사이트 | 카테고리 인덱스·10×10 진행판 라벨 |
| 생산 매뉴얼 | 카테고리 목록 |

## 5. 기존 2건 처리

`ki-b9-01`·`ki-b9-03`은 **자동으로 배정되지 않는다.**

정의를 넓혔다고 해서 이 두 후보가 자동으로 자격을 얻는 것은 아니다. 신규 정의(계속적 이용계약·의무사용기간·위약금·해지 절차)를 **본문이 실제로 지지하는지** 다시 판정해야 한다. 정식 annotation job으로 돌리고, 수기 배정하지 않는다.

두 후보 모두 의무사용기간·월 임대료·위약금·해지가 본문에 있으므로 통과 가능성은 높다고 본다. 다만 그 판정은 검토자가 한다.

## 6. 이 결정의 근거와 반증 조건

**근거**: 2건짜리 예외가 아니라 **반복될 도메인**이라는 판단이다. 정수기·비데·안마의자·매트리스·공기청정기 등 국내 소비자 계약에서 렌털은 흔하고, 생활과업을 표본으로 뽑는 한 계속 나온다.

**반증 조건**: 이후 배치에서 렌털 성격 후보가 실제로는 드물게 나온다면 통합의 근거가 약해진다. 그 경우 잠정 분류 표시를 근거로 되돌릴 수 있다.

## 7. Claude Code가 하지 않은 것

enum·schema·READY 생성기·사이트는 Codex 소유다. 이 문서는 실행 사양이며 구현은 포함하지 않는다. Claude Code는 현재 독립 검토자로 고정돼 대기 중이다.
